# 🧠 Next Store Pro — Backend API

A scalable and secure backend server built with **TypeScript**, **Node.js**, and **Express.js**, powering the eCommerce platform for digital products. This RESTful API manages authentication, product listings, orders, and media storage.

---

## ⚙️ Tech Stack

- **Node.js** + **Express.js**
- **TypeScript**
- **MongoDB** + **Mongoose**
- **Cloudinary** for image uploads
- **JWT** for authentication & authorization
- **Postman** for API documentation and testing

---

## 🔥 Key Features

- 🔐 JWT authentication using access and refresh tokens
- 🛍️ Product CRUD operations with image uploads to Cloudinary
- 🧾 Order creation and retrieval for users
- 👤 User roles and permission handling
- 💾 MongoDB schemas for users, products, and orders
- 🌐 RESTful API with secure endpoints
- 🧪 Postman collection for easy API testing

---

## 🖥️ Getting Started

```bash
# Clone frontend repo
https://github.com/developersajadur/Next-Store-Server-Side.git
```
```bash
cd next-store-pro
```
```bash
# Install dependencies
npm install
```

# Create an environment configuration
cp .env.example .env

# Start development
```bash
npm run dev
```
