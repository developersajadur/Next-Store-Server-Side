# 🛒 Next Store Pro

**Live Site:** [https://next-store-pro.vercel.app](https://next-store-pro.vercel.app)  
A full-stack eCommerce platform for digital products built using **Next.js**, **Redux**, **Tailwind CSS**, **ShadCN UI**, **Node.js**, **Express**, **MongoDB**, and **TypeScript**.

---

## 🌐 Frontend Overview

### 🚀 Features

- 🔥 **Next.js 14** with **TypeScript** for fast server-side rendering and SEO optimization  
- 🎨 **Tailwind CSS** for sleek and modern UI styling  
- 🧩 **ShadCN UI** components for flexible and accessible design  
- 🛍️ **Redux Toolkit** for global state management (cart, auth, etc.)  
- 🛒 Cart management with persistent state using **Redux + TypeScript**  
- 💳 **SurjoPay integration** for secure online transactions  
- 🔐 **JWT Authentication** for protected routes and user sessions  
- 🧠 Optimized digital product catalog with category filtering  
- ✅ Order summary, checkout, and payment confirmation pages

---

## 🧰 Frontend Tech Stack

- **Framework:** Next.js + TypeScript  
- **State Management:** Redux Toolkit  
- **Styling:** Tailwind CSS, ShadCN UI  
- **Authentication:** JWT  
- **Payments:** SurjoPay  
- **Deployment:** Vercel

## 🖥️ Getting Started (Frontend)

```bash
# Clone frontend repo
https://github.com/developersajadur/Next-Store-Server-Side.git
```
```bash
cd next-store-pro
```
```bash
# Install dependencies
npm install
```

# Start development
```bash
npm run dev
```
